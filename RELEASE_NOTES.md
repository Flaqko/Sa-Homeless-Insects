# Homeless Insects v1.0

A small immersion mod that gives ambient homeless pedestrians a **70% chance** to have flies/insects around them using GTA San Andreas' built-in `INSECTS` FX.

The mod does not rely on a hardcoded skin list. It detects `STAT_TRAMP_MALE` and `STAT_TRAMP_FEMALE` directly, so replacement and add-on homeless skins work automatically when configured with the proper ped stats.

### Highlights

- 70% chance, rolled once per ped lifetime
- Very lightweight 2-second discovery scan
- Character-attached built-in `INSECTS` FX
- No constant movement tracking
- Supports custom/replacement/add-on homeless skins
- Ignores mission/script-created peds

### Requirements

GTA San Andreas Classic 1.0 US + CLEO Redux JavaScript.

**Important:** keep `[mem]` in the script filename because this mod reads GTA SA memory.
